# Materiale caricato dal proprietario

Il repo è PUBBLICO: tutto ciò che metti qui è visibile a chiunque. Prima di caricare:

1. Oscura email, nome, saldi reali, numeri di conto, notifiche private, token, QR code. Usa dati demo.
2. Niente chiavi API, file `.env` o screenshot di pannelli di configurazione.
3. Controlla che nell'inquadratura non ci siano altre app o chat.

## Come caricare

- Screenshot: `brand/uploads/screenshot/AAAA-MM-GG_<cosa-mostra>.png`
- Screen recording: `brand/uploads/recordings/AAAA-MM-GG_<cosa-mostra>.mp4` (meglio sotto i 25 MB, 1080x1920, max 60 s)
- Opzionale: una riga per file in `brand/uploads/NOTE.md` (cosa mostra, quale funzione, quale versione dell'app).

Il manager usa solo ciò che trova qui o in `brand/`, e cita sempre il percorso del file.
I video non vengono "guardati" dal manager: scrivi in `NOTE.md` cosa succede secondo per secondo (anche in 3 righe),
così può scrivere script fedeli.
