# Trend links (opzionale)

Questo file è un EXTRA. Il manager cerca i trend da solo ogni settimana sul web
pubblico (articoli, report di trend, YouTube Shorts, TikTok pubblico, pagine
pubbliche di creator) e funziona anche se questo file resta vuoto.

Se vuoi aiutarlo, incolla qui link o appunti. Il manager li legge ogni
lunedì e li tratta come segnali in più, non come verità.

```
- URL o descrizione | perché mi piace | account/nicchia
```
